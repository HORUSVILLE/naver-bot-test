# 재료 최저가 (발주 도우미)

자주 사는 재료를 목록에 올려두고, 누르면 국내 쇼핑몰 최저가를 찾아 **구매 페이지를 바로 열어주는** 웹앱입니다.
수량 선택과 결제는 열린 쇼핑몰 화면에서 직접 하시면 됩니다.

## 사용 흐름

1. **+ 재료 추가**로 재료를 등록합니다. 이름은 꼭 넣어야 하고, 검색어·제외어·메모는 선택입니다.
2. 재료를 누르면 네이버쇼핑에 모인 쇼핑몰(11번가, G마켓, 옥션, SSG, 스마트스토어 등)에서 가격을 비교합니다.
3. 맨 위 **최저가** 카드의 버튼을 누르면 해당 쇼핑몰의 상품 페이지가 새 창으로 열립니다.
4. 수량과 결제는 그 화면에서 직접 진행합니다.

### 검색이 정확하게 나오게 하는 요령

| 칸 | 예시 | 효과 |
|---|---|---|
| 검색어 | `하얀설탕 15kg` | 여기 적은 **모든 단어가 들어간 상품만** 남깁니다. 용량을 넣으면 같은 규격끼리 비교됩니다. |
| 제외할 단어 | `스틱, 시럽, 각설탕` | 이 단어가 들어간 상품은 결과에서 뺍니다. |

- **단위가격순** 정렬을 고르면 상품명에서 용량(15kg, 500g x 2개, 18L, 30구 등)을 읽어 100g·100ml·1개당 가격으로 비교합니다. 상품명에서 읽은 추정치라 틀릴 수 있습니다.
- 가격에 **배송비는 포함되지 않습니다.** 네이버 API가 배송비를 알려주지 않기 때문입니다.
- **쿠팡은 네이버쇼핑에 없어서** 결과 화면 아래 "쿠팡" 링크로 따로 확인해야 합니다.
- 재료 목록은 **이 휴대폰 브라우저에만 저장**됩니다. 기기를 바꿀 때는 ⋯ 메뉴의 내보내기·가져오기를 쓰세요.

## 1단계: 네이버 API 키 발급 (무료, 하루 25,000회)

1. https://developers.naver.com/apps 에 네이버 아이디로 로그인합니다.
2. **애플리케이션 등록**을 누르고 아래처럼 입력합니다.
   - 사용 API: **검색**
   - 환경: **WEB 설정**, 웹 서비스 URL: 배포 주소 (모르면 일단 `http://localhost:8000`)
3. 등록이 끝나면 나오는 **Client ID**와 **Client Secret**을 복사해 둡니다.

키가 없어도 앱은 실행됩니다. 이때는 **샘플 모드**라 가짜 가격이 나오니 화면 구성만 확인하세요.

## 2단계: 내 컴퓨터에서 실행해보기

```bash
cd order_app
pip install -r requirements.txt
export NAVER_CLIENT_ID=발급받은_ID
export NAVER_CLIENT_SECRET=발급받은_Secret
uvicorn server:app --reload --port 8000
```

브라우저에서 http://localhost:8000 을 엽니다.

## 3단계: 휴대폰에서 쓰기 (Render 무료 배포)

1. https://render.com 에 GitHub 계정으로 가입합니다.
2. **New → Blueprint**를 누르고 이 저장소를 고릅니다. 루트의 `render.yaml`을 자동으로 읽습니다.
3. 환경변수를 넣습니다.
   - `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`: 1단계에서 받은 값
   - `ACCESS_CODE`: (권장) 아무 비밀번호. 주소를 아는 다른 사람이 내 API 사용량을 쓰지 못하게 막습니다.
4. 배포가 끝나면 `https://order-app-xxxx.onrender.com` 같은 주소가 나옵니다. 휴대폰으로 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.
5. 네이버 개발자센터의 웹 서비스 URL을 이 주소로 바꿔줍니다.

> Render 무료 플랜은 15분 동안 접속이 없으면 잠듭니다. 그 뒤 첫 접속은 30초 정도 걸릴 수 있습니다.

## 파일 구성

```
order_app/
  server.py        웹 서버 (FastAPI)
  shopping.py      네이버 쇼핑 검색, 관련 상품 필터, 용량·단위가격 계산
  static/          화면 (index.html, app.js, style.css)
  tests/           테스트 (pytest)
```

테스트 실행: `cd order_app && python -m pytest -q`
