# 재료 최저가 (발주 도우미)

자주 사는 재료를 목록에 올려두는 웹앱입니다. 재료의 **최저가** 버튼을 누르면 쇼핑몰이 **낮은 가격순 검색 결과**로 바로 열립니다.
수량 선택과 결제는 열린 쇼핑몰 화면에서 직접 하시면 됩니다.

API 키도 서버도 필요 없습니다. 네이버 쇼핑 검색 API는 2026년 7월 31일에 종료되어, 이 앱은 쇼핑몰 검색 화면을 직접 여는 방식을 씁니다.

## 사용 흐름

1. **+ 재료 추가**로 재료를 등록합니다.
   - 이름은 꼭 넣어야 합니다.
   - 검색어는 선택입니다. `백설 하얀설탕 15kg`처럼 **용량까지 넣으면** 같은 규격끼리 비교되어 더 정확합니다.
2. 재료 카드의 초록색 **최저가** 버튼을 누르면 기본 사이트가 낮은 가격순으로 열립니다. 처음 기본값은 네이버쇼핑입니다.
3. 아래쪽 작은 버튼으로 다른 사이트(쿠팡, 다나와)도 바로 열 수 있습니다.
4. 열린 화면에서 맨 위 상품을 골라 수량을 정하고 결제합니다.

## 사이트

| 사이트 | 포함 범위 | 휴대폰에서 열리는 곳 | 낮은가격순 확인 |
|---|---|---|---|
| 네이버쇼핑 | 11번가, G마켓, 옥션, SSG, 스마트스토어 등 대부분의 쇼핑몰 | **네이버 앱** (설정에서 끄면 브라우저) | ✅ 휴대폰(크롬, 네이버 앱)에서 확인 |
| 쿠팡 | 쿠팡 (네이버쇼핑에는 없음) | **쿠팡 앱** (설치되어 있으면 자동) | ✅ 휴대폰(쿠팡 앱)에서 확인 |
| 다나와 | 가격비교 사이트 | 브라우저 | ✅ 확인 |

### 네이버 앱으로 열기

- ⋯ 메뉴의 **"네이버는 네이버 앱으로 열기"**가 기본으로 켜져 있습니다.
- **아이폰:** 앱이 안 열리면 화면 아래에 **"웹으로 열기"** 안내가 8초 동안 뜹니다. 네이버 앱이 없다면 이 설정을 꺼주세요.
- **안드로이드:** 네이버 앱이 없으면 자동으로 브라우저가 열립니다.

### 참고

- 열린 화면이 낮은 가격순이 아니면, 그 화면에서 정렬을 "낮은 가격순"으로 한 번 바꿔주세요.
- 네이버쇼핑과 쿠팡은 맨 위에 **광고 상품**이 먼저 나올 수 있습니다.
- 표시 가격에 **배송비가 빠져 있을 수 있습니다.**
- ⋯ 메뉴에서 **최저가 버튼이 여는 기본 사이트**를 바꿀 수 있습니다.
- 사이트를 추가하려면 `sites.js`의 목록에 한 줄을 넣으면 됩니다.

## 저장

재료 목록은 **이 휴대폰 브라우저에만 저장**됩니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 ⋯ 메뉴의 **파일로 내보내기**로 백업하세요.

## 휴대폰에서 쓰기 (GitHub Pages 무료 배포)

1. 이 브랜치를 `main`에 합칩니다.
2. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
3. **Actions** 탭에서 **Order App (GitHub Pages)**가 끝나면 `https://horusville.github.io/naver-bot-test/` 주소가 생깁니다.
4. 휴대폰으로 그 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

> 비공개(private) 저장소는 GitHub 무료 요금제에서 Pages를 쓸 수 없습니다. 이 경우 Netlify Drop(https://app.netlify.com/drop)에 `order_app` 폴더를 끌어다 놓아도 됩니다.

내 컴퓨터에서 바로 열어보려면 `order_app/index.html` 파일을 브라우저로 열면 됩니다.

## 파일 구성

```
order_app/
  index.html   화면
  app.js       재료 목록, 추가·편집, 백업
  sites.js     쇼핑몰별 "낮은 가격순" 검색 주소
  style.css    디자인
  tests/       테스트 (node --test order_app/tests/*.test.js)
```
